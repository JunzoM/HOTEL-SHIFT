# FIXED550 macOS表示統一の確認記録

## 共通基準

Mac Catalystに限り、画面見出しを中央に配置。広い画面は日付／見出し／店舗切替の左右等幅3列、狭い画面は見出しと店舗切替の2段。本文外側16pt、共通の淡い背景、大きなカードの角丸14pt、主要操作は標準bordered／borderedProminent。iPhoneのフローティングメニューとタブ最小化は維持。

本文の有効幅700pt未満ではcompact環境を適用し、画面ごとの表示判断を統一。スタッフの一覧と詳細は650pt未満で上下配置へ切替。

## 表示確認の制限

Computer Useで既存HOTEL SHIFTアプリを開こうとしたが「Computer Use permissions are not granted」で拒否された。このため実画面のスクリーンショット比較、クリック操作、ウィンドウ幅変更による視覚検証は未実施。上表はコードの確認結果であり、実描画確認の完了を示すものではない。

印刷帳票の描画、データ処理、保存形式は変更していない。
