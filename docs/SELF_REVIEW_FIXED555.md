# FIXED555 セルフレビュー

## 見つかった問題と修正

1. PDFの失敗キャッシュを複数呼出元が待機すると、同じキーで再生成が重複する。古い試行の失敗処理が同じキーの新しい試行を消す可能性もある。キーだけの比較から試行IDの比較へ変更し、置換済みタスクへ合流する。前回の店舗・データ版・キャンセル検証は維持。
2. 店舗別と表示していた人件費予算が全店舗共通の保存キーだった。店舗UUID別に保存し、既存の共通値は未設定店舗の初期値として保持。別ウィンドウの更新を上書きしないよう保存直前に最新の保存データを読み直す。編集中に店舗が変わった場合は保存しない。
3. 予算の負号・英字を除去していたため「-100」が「100」に変わり、不正値でも編集画面を閉じていた。入力全体を検証し、不正値はエラー表示して保存不可とする。全角数字、正常な3桁区切り、円記号付きの金額は受け付ける。整数上限超過・負数・小数・空欄・文字混入を拒否。
4. PDF・CSV・JSONのファイル名に店舗名を無制限に含めていた。出力ファイル名だけ制御文字等を除去し、文字境界を保って120 UTF-8 bytes以内へ制限。書類中の正式な店舗名は変更しない。人件費CSVも共通処理へ統一。

## 回帰検証

- verify_fixed554_pdf.py: 前回の10ケースを継続実行。
- verify_fixed555_pdf.py: 上記に同時待機者の生成失敗／ファイル欠損後の再生成を加えた12ケース。FIXED554では重複生成を検出して失敗、FIXED555では成功。
- verify_fixed555_budget.py: 旧設定引継ぎ、店舗分離、ゼロ、整数上限、上限超過、全角・アラビア数字、不正な符号・区切りなど32項目。
- verify_fixed555_filename.py: 空文字、長い日本語・ASCII・絵文字、制御文字等9ケース。実際に一時ファイルを書き込み確認。

確認はコードとテストによるもので、実機のタップ操作や画面表示は未検証。全コードからすべてのバグを排除できたという保証ではない。
